視差滾動效果

作者：Vineet Kumar

什麼是視差滾動？

視差滾動是一種網頁設計技術，背景會以比前景更慢的速度移動。當訪客向下捲動時會產生 3D 效果，增加畫面的深度並營造更沉浸的瀏覽體驗。視差效果源自光學錯覺：人眼會覺得靠近的物體 比遠處更大，而遠處的物體看起來移動得較慢。這種錯覺被廣泛應用在不同媒介中以營造真實感， 最早可追溯至迪士尼《白雪公主》這類傳統動畫，以及《超級瑪利歐》等電玩作品。隨著 CSS 與 HTML 的進步，視差效果也發展成現今的網頁設計形式。

2007 年，開發者 Glutnix 在部落格中分享了早期的瀏覽器視差滾動實作，提供了支援 Internet Explorer 6 等瀏覽器的 JavaScript 與 CSS 2 範例與示範。直到 2011 年 HTML5 與 CSS3 風行後， 這項技術才在網頁設計圈普及。支持者認為視差是展現網頁流動性的簡單方法，常用作提升互動與 體驗的工具。不過，普渡大學在 2013 年的研究也指出：「雖然視差滾動提升了使用者體驗的某些 面向，但並不一定能改善整體體驗。」


為什麼要使用視差圖像？

    設計師應該嘗試視差圖像的兩個主要原因：

  • 幫助講述故事

    視差圖像很適合用來說故事。好的設計在於溝通，而網站設計就是要和訪客交流，講述關於 產品、服務或品牌的動人故事。視差滾動能讓訪客沉浸在獨特的線上體驗中，甚至可以打造單 頁網站，讓使用者不必跳轉頁面就能讀完整個品牌故事。

  • 提升使用者互動

    視差圖像也能提升互動性。降低網站跳出率是設計時的重要目標，跳出率代表訪客只看一頁就 返回或關閉分頁的比例，過高會影響搜尋排名。精心打造的視差頁面能帶來動態的體驗，通常 能讓使用者停留更久。


若想在網站加入視差滾動效果，可參考以下提示：

  • 選擇性使用

    視差滾動用在特定元素時效果最佳，不必在所有頁面或全程套用。可放在頁首、標題或僅限首 頁，讓視差為設計加分，而非分散注意。

  • 壓縮圖片

    視差滾動會用到多種媒體與 CSS 形狀來營造深度，不希望因為圖片過大而拖慢載入，影響效能 與體驗。

  • 善用色彩

    視差不僅是前景與背景的圖像，也包含色彩。背景可採較低飽和度，前景使用鮮明色彩，營造 更強烈的深度感。
